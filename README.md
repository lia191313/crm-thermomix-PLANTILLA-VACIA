# CRM Thermomix · plantilla vacía

App para llevar clientes, llamadas, recordatorios, ventas y listados.
Esta copia **no contiene datos de nadie**: cada persona la conecta a su propia
base de datos de Supabase.

[![Deploy to Netlify](https://www.netlify.com/img/deploy/button.svg)](https://app.netlify.com/start/deploy?repository=https://github.com/lia191313/crm-thermomix-PLANTILLA-VACIA)

Las instrucciones paso a paso están en la guía que acompaña a esta plantilla
(`GUIA_PASO_A_PASO`). Lo primero es crear las tablas con `1_CREAR_TABLAS.sql`.

Tu app de clientes Thermomix

Guía paso a paso para ponerla en marcha tú sola. Sin programar: solo crear cuentas, pulsar botones y copiar y pegar.

Antes de empezar:
  • Hazlo desde un ordenador (el móvil solo al final, para instalar la app).
  • Reserva 1 hora tranquila. Solo se hace una vez.
  • Ten a mano tu correo (te llegarán correos de confirmación).
  • Ten un papel o una nota para apuntar 3 cosas que irán saliendo.
  • Las páginas están en inglés. En esta guía pongo el nombre exacto de cada botón así y lo que significa (en cursiva).
Los pasos
  1. Crear tu cuenta de GitHub (donde se guarda tu copia de la app)
  2. Crear tu base de datos en Supabase (donde se guardan tus clientes)
  3. Publicar la app con Netlify (lo que la pone en internet)
  4. Decirle a Supabase cuál es la dirección de tu app
  5. Crear tu usuario y contraseña, y cerrar la puerta
  6. Instalar la app en el móvil y en el ordenador
  7. Cuidados del día a día
  8. Opcional: poner tus pueblos en "Mi zona"
  9. Opcional: tus frases de llamada y tus zonas
  10. Opcional (avanzado): avisos al móvil

Paso 1 · Cuenta de GitHub

GitHub es donde se guarda tu copia de la app. Con esta cuenta entrarás también en Supabase y Netlify, así solo tienes que recordar una contraseña.

  1. Entra en github.com y pulsa Sign up (registrarse).
  2. Pon tu correo, una contraseña y un nombre de usuario (por ejemplo maria-tmx).
  3. Te pedirá resolver un pequeño juego para comprobar que eres una persona, y te mandará un código al correo: cópialo en la página.
  4. Si te hace preguntas (para qué lo vas a usar, etc.), puedes pulsar Skip (saltar). Si pregunta por un plan, elige el gratis Free.
✅ Vas bien si ves la página de inicio de GitHub con tu nombre de usuario arriba a la derecha.

📝 Apunta: tu correo y contraseña de GitHub.

Paso 2 · Base de datos en Supabase

2.1 · Crear la cuenta y el proyecto

  1. Entra en supabase.com y pulsa Start your project (empieza tu proyecto).
  2. Pulsa Continue with GitHub (entrar con GitHub) y luego Authorize (autorizar).
  3. Si te pide crear una "organización", ponle tu nombre, elige el plan Free (gratis) y continúa.
  4. Pulsa New project (proyecto nuevo) y rellena:
    • Project name (nombre): crm-thermomix
    • Database password (contraseña de la base de datos): pulsa Generate a password (generar) y cópiala y guárdala en un sitio seguro. No la necesitarás en el día a día, pero no la pierdas.
    • Region (dónde están los ordenadores): elige una de Europa, por ejemplo West EU (Ireland) o Central EU (Frankfurt).
    • Si ves casillas de "Data API" o "Security", déjalas como vienen.
  5. Pulsa Create new project (crear) y espera 2 o 3 minutos a que termine de prepararse.

📝 Apunta: la contraseña de la base de datos.

2.2 · Crear las tablas (pegar el SQL)

Ahora vas a crear los "cajones" vacíos donde se guardarán tus clientes, llamadas, ventas, etc.

  1. Abre el archivo 1_CREAR_TABLAS.sql. Te lo han pasado junto a esta guía, y también está en tu GitHub (Paso 3), dentro de tu copia de la app. Ábrelo con el Bloc de notas: clic derecho → Abrir con → Bloc de notas.
  2. Selecciona todo el texto (Ctrl + E en Windows, o Ctrl + A) y cópialo (Ctrl + C).
  3. En Supabase, en el menú de la izquierda, pulsa SQL Editor (editor SQL, un icono como una ventanita con >_ ).
  4. Pulsa + New query (consulta nueva), haz clic en el recuadro grande en blanco y pega (Ctrl + V).
  5. Pulsa Run (ejecutar), abajo a la derecha.
  6. Si sale un aviso que dice algo como "Potential issue detected… destructive operation" (posible operación peligrosa), es normal: el archivo está preparado para poder repetirse sin romper nada. Pulsa Run this query (ejecutar igualmente).
✅ Vas bien si abajo aparece una lista de 25 tablas (anotaciones, comisiones, contacts, demos, equipo, eventos…) y todas dicen true en la columna rls_activo.
Si sale un error en rojo: no pasa nada, no se ha estropeado nada. Vuelve a pegar el texto entero y pulsa Run otra vez. Si sigue saliendo, haz una foto de pantalla del mensaje rojo y pide ayuda (ver "Si algo falla" al final).

2.3 · Copiar tus 2 claves

La app necesita saber dónde está tu base de datos. Son dos datos. Los dos son públicos (no son contraseñas), pero cópialos con cuidado.

  1. Arriba en la página de tu proyecto, pulsa el botón Connect (conectar). Si no lo ves, ve a la ruedecita Project Settings (ajustes) del menú de la izquierda.
  2. Dato 1 · Project URL (dirección del proyecto): algo como https://abcdefghijk.supabase.co. En ajustes está en Data API.
  3. Dato 2 · la clave pública: en ajustes, en API Keys. Es la que se llama Publishable key (clave publicable, empieza por sb_publishable_). Si en tu pantalla sale en cambio anon public (un texto muy largo que empieza por eyJ), usa esa.
Nunca uses ni compartas la clave llamada secret o service_role. Esa sí es como una llave maestra.

📝 Apunta (copia y pega en tu nota): el Project URL y la Publishable key.

Paso 3 · Publicar la app con Netlify

  1. Abre esta dirección: github.com/lia191313/crm-thermomix-PLANTILLA-VACIA
    (Si te han pasado otro enlace, usa ese.)
  2. Baja un poco hasta ver el botón verde-azulado Deploy to Netlify (publicar en Netlify) y púlsalo.
  3. Netlify te pedirá entrar: pulsa GitHub y luego Authorize (autorizar). Si te pregunta algo sobre tu equipo o para qué la usas, rellénalo como quieras o sáltalo.
  4. Te pedirá Connect to GitHub (conectar con GitHub): acéptalo. Así se crea tu propia copia de la app en tu GitHub. Es tuya y no depende de nadie.
  5. Te pedirá un nombre para tu copia (Repository name): por ejemplo mi-crm-thermomix. Si te ofrece hacerlo privado (Private), márcalo.
  6. Aparecerán dos casillas. Pega tus datos del Paso 2.3:
    CasillaQué pegar
    VITE_SUPABASE_URLtu Project URL (https://….supabase.co)
    VITE_SUPABASE_ANON_KEYtu Publishable key (sb_publishable_…)
    Cuidado con no dejar espacios al principio o al final.
  7. Pulsa Save & Deploy (guardar y publicar) y espera 3 o 4 minutos.
✅ Vas bien si en Netlify sale Published (publicado) y una dirección tipo https://nombre-raro-12345.netlify.app.

3.1 · Ponerle un nombre bonito a la dirección

  1. En Netlify, dentro de tu web, ve a Site configuration (configuración) → Change site name (cambiar nombre). En algunas pantallas está en Project configuration → Change project name.
  2. Escribe por ejemplo clientes-maria y guarda. Tu app quedará en https://clientes-maria.netlify.app.

📝 Apunta: la dirección de tu app (…netlify.app).

Si al abrir tu app sale un recuadro amarillo "Plantilla vacía · configura tu Supabase", es que las claves no han llegado. En Netlify: Site configuration → Environment variables (variables), revisa que estén las dos bien escritas, y después Deploys → Trigger deploy → Deploy site (volver a publicar).

Paso 4 · Decirle a Supabase la dirección de tu app

Esto hace que los correos de "confirma tu cuenta" y "olvidé mi contraseña" te lleven a tu app.

  1. En Supabase, menú izquierdo: Authentication (acceso de usuarios) → URL Configuration.
  2. En Site URL pega la dirección de tu app, por ejemplo https://clientes-maria.netlify.app, y pulsa Save (guardar).
  3. En Redirect URLs pulsa Add URL (añadir), pega la misma dirección terminada en /** (por ejemplo https://clientes-maria.netlify.app/**) y guarda.

Paso 5 · Tu usuario y contraseña (y cerrar la puerta)

  1. Abre tu app (tu dirección …netlify.app) en el ordenador.
  2. Pulsa "¿No tienes cuenta? Regístrate", pon tu correo y una contraseña que vayas a recordar, y pulsa Crear cuenta.
  3. Te llegará un correo de Supabase: abre el enlace para confirmar. Te llevará a tu app.
  4. Entra con tu correo y contraseña. 🎉 Ya estás dentro, con la app vacía.
Si no te llega el correo (mira también en Spam/Correo no deseado): en Supabase ve a Authentication → Users → Add user → Create new user, pon tu correo y contraseña, marca Auto Confirm User (confirmar ya) y créalo. Después entra en la app con esos datos.

5.1 · Cerrar la puerta (¡importante!)

Ahora que ya tienes tu usuario, impide que nadie más pueda crearse una cuenta en tu app:

  1. En Supabase: Authentication → Sign In / Providers (formas de entrar; en algunas pantallas se llama Settings).
  2. Desactiva Allow new users to sign up (permitir registros nuevos) y pulsa Save.
  3. Comprueba en Authentication → Users que solo sales tú.
✅ Listo: solo tú puedes ver tus datos, y solo después de entrar con tu contraseña.

Paso 7 · Cuidados del día a día

  • Copia de seguridad una vez al mes: en el menú de la app, botón Exportar. Se descarga un archivo con todos tus datos: guárdalo en tu ordenador o en tu Drive.
  • Si un día la app no carga datos después de unas vacaciones: el plan gratis de Supabase "duerme" el proyecto si no se usa en una semana. Tus datos no se pierden. Entra en supabase.com, abre tu proyecto y pulsa Restore project (despertar). Tarda unos minutos.
  • Si olvidas la contraseña de la app: en la pantalla de entrada, "¿Olvidaste tu contraseña?". Te llega un correo para poner otra.
  • Lo que nunca debes compartir: tu contraseña de la app, la de GitHub, la de la base de datos y la clave "secret"/"service_role" de Supabase.
  • Novedades de la app: si alguna vez sale el aviso "Hay una versión nueva — Actualizar", púlsalo.

Opcional · Poner tus pueblos en "Mi zona"

La app puede marcar a los clientes de tu zona (para invitarlos a clases presenciales). Puedes marcarlo a mano en cada ficha, o hacer que se marque solo según el pueblo:

  1. En tu GitHub, abre tu copia de la app → carpeta src → utils → archivo zonaPlaya.ts.
  2. Pulsa el lápiz ✏️ (editar).
  3. Cambia la línea export const MUNICIPIOS_ZONA_PLAYA: string[] = []; por tus pueblos, entre comillas y separados por comas. Por ejemplo:
    export const MUNICIPIOS_ZONA_PLAYA: string[] = ["Sabadell", "Terrassa", "Sant Quirze"];
  4. Pulsa Commit changes… (guardar cambios) y otra vez Commit changes. Netlify vuelve a publicar la app sola en 3 minutos.

Opcional · Poner tus frases de llamada y tus zonas

Se cambian igual que "Mi zona" (abrir el archivo en tu GitHub → lápiz ✏️ → cambiar → Commit changes):

  • Frases de llamada de "Mi día": archivo src/lib/frasesLlamadas.ts. Cambia [tu nombre] por tu nombre y, si quieres, las frases por las tuyas. Cada frase va entre comillas.
  • Zonas de los listados (para agrupar a la gente por pueblos): archivo src/lib/zonas.ts. Ya trae los pueblos de la provincia de Barcelona; lo que no esté sale en "Lejos / otros".

Todo lo demás (promociones, objetivos del mes, equipo, calendario, comisiones, plantillas de mensajes) se rellena desde la propia app, sin tocar nada aquí.

Opcional (avanzado) · Avisos al móvil

La app funciona perfectamente sin esto. Sin avisos al móvil, los recordatorios te salen al abrir la app (ventana del día) y en el panel de inicio.

Los avisos al móvil con la app cerrada necesitan pasos técnicos (programas en la línea de comandos). Recomendación: déjalo para más adelante y hazlo con alguien que sepa un poco de informática, o pidiéndole ayuda a un asistente como Claude con esta lista:

  1. Generar un par de claves VAPID (por ejemplo con npx web-push generate-vapid-keys).
  2. Publicar las 3 funciones de la carpeta supabase/functions de tu copia con la herramienta Supabase CLI: notify-due-reminders y snooze-reminder con --no-verify-jwt, y notify-snooze-broadcast normal.
  3. En Supabase → Edge Functions → Secrets, añadir: VAPID_PUBLIC_KEY, VAPID_PRIVATE_KEY, VAPID_SUBJECT (mailto:tu correo), CRON_SECRET y SNOOZE_SECRET (dos textos largos inventados).
  4. Ejecutar 2_OPCIONAL_NOTIFICACIONES.sql en el SQL Editor, cambiando antes las 2 líneas marcadas.
  5. En Netlify → Environment variables, añadir VITE_VAPID_PUBLIC_KEY con la clave pública VAPID, y volver a publicar (Trigger deploy).
  6. En la app, activar las notificaciones desde el móvil y aceptar el permiso.

Si algo falla

Lo que vesQué hacer
Recuadro amarillo "Plantilla vacía · configura tu Supabase"Faltan o están mal las 2 claves en Netlify. Ver el aviso del Paso 3.
"Error de conexión con la base de datos" o "Invalid API key"Alguna clave tiene un error o un espacio. Vuelve a copiarlas de Supabase (Paso 2.3) a Netlify y vuelve a publicar.
Entras, pero al guardar un cliente sale un error tipo "permission denied" o "relation does not exist"Las tablas no se crearon bien. Repite el Paso 2.2 (pegar el SQL entero y Run). No se borra nada.
"Email not confirmed"Busca el correo de confirmación (también en Spam), o usa el plan B del Paso 5.
"Signups not allowed"Ya cerraste la puerta (Paso 5.1). Es correcto. Si necesitas otro usuario, vuelve a activarlo un momento.
La app no se actualizaCierra la app del todo y vuelve a abrirla.
Tranquila: mientras la estás montando, la app está vacía. Si algo sale muy mal, puedes borrar el proyecto de Supabase o la web de Netlify y empezar de nuevo, sin perder nada. Y nada de lo que hagas aquí puede afectar a la app de otra persona: cada una tiene sus propias cuentas.
